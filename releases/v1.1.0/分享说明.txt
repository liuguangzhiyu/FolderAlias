文件夹中文别名 · FolderAlias 1.1.0

只需要把 FolderAlias-Setup-1.1.0-x64.exe 发给别人。

接收者：
1. 普通双击 EXE，选择新的或空的安装目录。
2. 默认“第一层右键菜单”需要同意专用证书并接受一次 Windows 管理员确认。
3. 安装后右键文件夹，选择“设置中文显示名…”。
4. 卸载在 Windows“已安装的应用”里，或再次运行安装包。

适用 Windows 11 x64。离线运行，使用系统自带 .NET Framework 4.8。
没有管理员权限可选普通菜单，在“显示更多选项”里使用。

这是个人分享版，使用专用自签名证书。Windows 仍可能提示未知发布者/SmartScreen；不应关闭系统保护。第一层菜单注册只将专用证书加入“受信任的人”，不加入根证书。

菜单布局和 desktop.ini 显示效果受 Windows 版本及缓存影响，不保证每个视图都立即显示中文名。实际路径不改名。

FolderAlias-1.1.0-source.zip 是完整源码和测试说明，普通使用者不需要它。
