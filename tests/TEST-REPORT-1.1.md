## 真实安装和卸载

普通菜单安装到含中文、空格、英文撇号和 `&` 的工作测试目录，成功注册。卸载前额外加入一个用户文件；卸载后用户文件保留、工具文件移除、安装和卸载登记清除，原来已有的普通菜单命令恢复。

获得用户明确同意后，使用交付 EXE 内的同一个安装引擎完成现代菜单安装：

- 通过 UAC 导入专用证书到 LocalMachine\TrustedPeople，Root 中没有该证书。
- 成功注册签名稀疏 MSIX 包，安装器内置的代理激活校验通过。
- 独立测试程序通过 `CoCreateInstance(CLSCTX_LOCAL_SERVER)` 激活已注册的 IExplorerCommand，读取标题和图标并通过上述选择状态检查。
- 调用真实 Invoke，选择 `E:\Tools\EcoPaste` 与含中文、空格、撇号、`&` 的测试目录。实际启动一个主程序进程；命令行保留两条完整路径，窗口标题正确，随后正常关闭该测试窗口。此步只读取文件夹，没有写入别名。
- 证书信任期间，Windows 对交付 EXE 的 Authenticode 校验返回 **Valid**。
- 通过同一个安装引擎卸载，测试目录移除、当前用户包数量回到 0、安装/卸载登记清除、旧版普通菜单恢复。
- 再通过 UAC 执行内置证书清理，退出码 0；TrustedPeople 中专用证书数量回到 0。没有留下测试主程序进程。

EcoPaste 原有别名配置及备份保留。更早的 1.0 实测已完成 EcoPaste 应用→还原→再应用，原有 16 个软件文件的名称、长度、SHA-256 保持不变；1.1 核心沿用该实现并重新通过 30 项回归。

## 界面和边界

安装界面以真实 WinForms 窗口渲染并检查截图；在当前高 DPI 缩放下主要文字、路径、选项和按钮可见。预览没有安装程序或导入证书。

**没有通过实际 Explorer 右键截图确认菜单排版或位置。** 已验证的是正式包注册、进程外 COM 激活、真实 Shell 选择对象和启动调用；菜单排序、分组、缓存与最终可见位置仍由 Windows 管理。

没有在另一台干净电脑、ARM64、不同 Windows 构建、企业策略环境、多账户并发或真实断电场景测试。没有验证下载来源引发的 SmartScreen 信誉提示；自签名不保证免提示。证书清理的“其他账户仍使用则保留”分支有实现，但没有创建第二账户进行实测。

本版本不是自动升级器；升级、更换目录或菜单类型要先卸载再安装。修改过的安装文件和用户文件会保留，不提供强制删除它们的快捷方式。
